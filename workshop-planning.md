# Preliminary Workshop Planning

**2026 Better Scientific Software Fellowship**  
**Project:** *Sustainable AI: Best Practices for Reproducible Scientific Software Development*  
**Fellow:** Suzan Anwar, Ph.D.

## Purpose

This document captures preliminary community workshop planning for Milestone 2. It is intentionally a planning document: dates, collaborators, and delivery venues remain tentative until confirmed.

## Tentative Workshop Title

**AI-Assisted Reproducibility in Scientific Software: Practical Practices for Sustainable AI and HPC Workflows**

## Target Audience

The workshop is intended for:

- scientific software developers and research software engineers;
- researchers using AI/ML in computational science;
- HPC users and facilitators;
- faculty and students developing scientific software; and
- researchers seeking practical, lightweight approaches to reproducibility and software sustainability.

## Proposed Format

**Length:** 60–90 minutes  
**Format:** virtual or hybrid hands-on workshop  
**Level:** introductory to intermediate  
**Materials:** Best Practices Guide, Tutorials 1–7, reusable repository templates, and selected ReproPilot examples as a supporting case study.

## Learning Outcomes

By the end of the workshop, participants should be able to:

1. identify core reproducibility artifacts for scientific software projects;
2. distinguish artifact presence from artifact quality and applicability;
3. document environments, dependencies, tests, provenance, and HPC execution context;
4. explain the difference between reproducibility readiness and successful scientific reproduction;
5. identify appropriate and inappropriate roles for AI assistance in reproducibility work;
6. apply a human-in-the-loop, evidence-grounded approach to AI recommendations; and
7. select one or more concrete improvements for their own scientific software workflow.

## Tentative Agenda

| Time | Topic | Activity |
| --- | --- | --- |
| 0–10 min | Why reproducibility is difficult in modern scientific software | Motivation, AI/HPC context, readiness versus reproduction |
| 10–25 min | Core sustainable software practices | Documentation, dependencies, environments, testing, provenance |
| 25–40 min | HPC and AI-specific reproducibility | Compilers, MPI/GPU stacks, schedulers, seeds, model/data versions |
| 40–55 min | Responsible AI assistance | Grounded evidence, limitations, human oversight, unsupported claims |
| 55–75 min | Hands-on activity | Selected exercise from Tutorials 1–6 or a short repository assessment |
| 75–90 min | Case study and discussion | ReproPilot example, tradeoffs, participant questions, feedback |

For a 60-minute version, the hands-on and case-study segments can be shortened and combined.

## Candidate Hands-On Activities

Possible activities include:

- use Tutorial 1 to classify reproducibility evidence in a repository;
- use Tutorial 2 to improve an environment/dependency specification;
- use Tutorial 3 to design a scientifically meaningful test;
- use Tutorial 4 to build a minimal provenance record;
- use Tutorial 5 to separate scientifically essential HPC settings from site-specific settings;
- use Tutorial 6 to review AI-generated recommendations against verified evidence; or
- use Tutorial 7 as a short case study of evidence-grounded repository assessment.

The workshop should remain broader than ReproPilot. ReproPilot should be presented as one implementation example rather than as the workshop's central identity.

## Connection to Fellowship Deliverables

The workshop is designed to disseminate and test the fellowship's central recommendations. It also provides a pathway for collecting community feedback on the Best Practices Guide and tutorials before final publication.

The workshop should consistently reinforce three messages:

- reproducibility is a workflow and software-practice problem, not a single tool;
- AI-generated guidance should be grounded in evidence and reviewed by humans; and
- reproducibility-readiness indicators should not be presented as proof that a scientific result has been independently reproduced.
