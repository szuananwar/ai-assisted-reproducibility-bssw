# Tutorial Beta Testing Plan and Feedback Log

**2026 Better Scientific Software Fellowship**  
**Project:** *Sustainable AI: Best Practices for Reproducible Scientific Software Development*

## Purpose

This document provides a lightweight, repeatable process for beta testing the fellowship tutorial series and recording evidence for Milestone 2 review and Milestone 3 refinement.

Each testing activity follows:

**Prepared → Shared → Feedback Received → Revision Incorporated**

Beta testing should evaluate both execution and the learning experience.

### Status Definitions

- **Prepared:** executable draft, setup instructions, and feedback questions are ready.
- **Shared:** an identified tester has received the repository/tutorial link and a request to test it.
- **Feedback Received:** execution results and usability/technical observations are documented.
- **Revision Incorporated:** actionable feedback has been addressed or a documented decision not to change has been made.

## Beta Testing Instructions

Each tester should complete at least one relevant tutorial, follow the documented setup, note whether instructions and objectives are clear, report cells/commands that fail or confuse, estimate completion time, comment on usefulness, flag overclaims about reproducibility or AI, and suggest at least one improvement.

## Feedback Questions

1. Which tutorial(s) did you test?
2. What is your background or role?
3. Were the learning objectives clear?
4. Were the setup instructions sufficient?
5. Did all executable cells or commands work as expected?
6. Approximately how long did the tutorial take?
7. Which section was most useful?
8. Which section was least clear or most difficult?
9. Did the tutorial distinguish reproducibility readiness from successful scientific reproduction?
10. Did it appropriately describe the role and limitations of AI assistance?
11. Was the level appropriate for the intended audience?
12. What should be changed before final publication?

## Acceptance Criteria for Milestone 2 Beta Testing

The initial beta-testing requirement can be considered evidenced when the initial testing cycle progresses through **Prepared → Shared → Feedback Received → Revision Incorporated**, feedback includes usability and technical/scientific observations, setup/execution problems are documented, and appropriate improvements are addressed or explicitly considered.

## Milestone 3 Follow-Up

Milestone 3 should use this evidence to refine learning objectives, examples, execution instructions, expected completion times, and final publication quality. Additional beta testing can be added as the audience broadens.
